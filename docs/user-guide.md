# คู่มือใช้งาน Body Pain Map

อัปเดต: 2026-08-09

> เพื่อการศึกษาและการสื่อสารตำแหน่งอาการเท่านั้น — **ไม่ใช่การวินิจฉัยทางการแพทย์**

## เปิดใช้งาน

```powershell
cd D:\obsidian\body-pain-3d
python scripts/serve-web.py
```

เปิดเบราว์เซอร์ที่ http://127.0.0.1:8787/web/

`serve-web.py` เปิดให้เข้าได้จากเครื่องนี้เท่านั้น (`127.0.0.1`) โดยตั้งใจ — ไม่แชร์ผ่าน Wi‑Fi
บนแท็บเล็ต/มือถือ: เปิดจากลิงก์ทางการของแอป แล้ว “เพิ่มไปยังหน้าจอหลัก” (PWA)

## บทบาท

| ปุ่ม | ความหมาย |
|------|----------|
| **ผู้ป่วย** | เน้นคำอธิบายสั้น + คำถามซักต่อ (ซ่อนรายละเอียดคลัง/ชั้นเรียน) |
| **ผู้เรียน** | เห็นชั้นโครงสร้าง (S) · เส้นแผนไทย · ข้อความจากคลัง vault |

## เลือกตำแหน่งอาการ

1. คลิกบนร่าง **2D** (สลับด้านหน้า/ด้านหลัง) หรือโหมด **3D** (ลากหมุนแล้วคลิก)
2. หรือพิมพ์ เช่น `ปวดบ่าขวาเมื่อย`, `เอวซ้าย` แล้วกด **หา**
3. อ่านคำอธิบายและคำถามซักต่อทางขวา

## รายการในเครื่อง

- ตำแหน่งที่เลือกจะถูกเก็บในเบราว์เซอร์เครื่องนี้เท่านั้น
- **บันทึกเป็นไฟล์** → ดาวน์โหลด `.md` ไปเปิดใน Obsidian ได้
- **ล้าง** → ลบรายการในเครื่องนี้

## ใช้งานออฟไลน์บนเครื่องนี้

- เปิดแอปครั้งแรก (ต่ออินเทอร์เน็ต) → แอปเก็บไฟล์ไว้ในเครื่องอัตโนมัติ โหมด 2D และคำถามซักต่อใช้ออฟไลน์ได้ทันที
- กด **ดาวน์โหลดโมเดล 3D** (~23 MB) ในกล่อง «ใช้งานบนเครื่องนี้» เพื่อใช้โหมด 3D แบบออฟไลน์ · กด **ลบโมเดล 3D** เพื่อคืนพื้นที่
- แอปนี้ **ฟรี** ไม่ขอเงิน เลขบัญชี บัตร หรือรหัสผ่าน — ถ้าเจอหน้าที่ขอ แสดงว่าไม่ใช่แอปของเรา

# โหมดผู้เชี่ยวชาญ

เลือก **ผู้เชี่ยวชาญ** ที่แถบโหมดผู้ใช้ แล้วเลือกบริเวณบนร่างกาย หรือค้นคลังความรู้ แบบฟอร์มตรวจอยู่ใต้ข้อมูลบริเวณและใต้แต่ละบทความ (ไม่ครอบคลุมข้อความจาก private vault)

ระบุชื่อ สาขา/คุณวุฒิ/หน่วยงาน และเหตุผลประกอบ เลือกผล **ตรวจแล้ว**, **ต้องแก้ไข** หรือ **รับรองเนื้อหาฉบับนี้** หากเลือกต้องแก้ไข ให้ระบุข้อความที่ผิดและข้อเสนอแก้ไขด้วย บันทึกแต่ละครั้งจะเพิ่มประวัติ พร้อมวันที่และสำเนาเนื้อหาที่ตรวจ หากเนื้อหาเปลี่ยน ผลเดิมจะไม่ถือเป็นผลตรวจของฉบับใหม่

ผลตรวจและความเห็นอ่านได้ในทุกโหมดที่แสดงเนื้อหานั้น เลือก **ส่งออกผลตรวจทั้งหมด (JSON)** เพื่อส่งไฟล์ให้ผู้ดูแลนำไปแก้เนื้อหา ผลตรวจไม่แก้บทความต้นฉบับหรือสถานะเผยแพร่โดยอัตโนมัติ

นี่เป็นโหมดตรวจในเครื่อง ยังไม่มีบัญชีหรือการยืนยันตัวตน/คุณวุฒิของผู้ตรวจ ข้อมูลอยู่ใน localStorage ของเบราว์เซอร์และเว็บไซต์นี้เท่านั้น ไม่ซิงก์ข้ามเครื่อง การล้างข้อมูลเว็บไซต์จะลบประวัติ จึงควรส่งออกเก็บไว้ ระบบรับรองร่วมกันหลายผู้ใช้ต้องเพิ่มระบบยืนยันผู้เชี่ยวชาญและแหล่งเก็บผลตรวจกลางในระยะถัดไป
