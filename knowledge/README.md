# คลังความรู้สาธารณะ (knowledge/)

เนื้อหาในโฟลเดอร์นี้ถูกแปลงเป็น `data/knowledge.json` ด้วย `python scripts/build-knowledge.py`
แล้วให้แอปค้นในเครื่องผู้ใช้ (ตัดคำไทย + BM25) — แสดงผลพร้อมแหล่งอ้างอิงทุกครั้ง

## กติกา

1. **เขียนด้วยคำของทีมเอง** — ห้ามคัดลอกข้อความ ภาพ หรือสไลด์จากตำรา/อาจารย์มาทั้งย่อหน้า
2. **ทุกไฟล์ต้องมีแหล่งอ้างอิง** (`source`) ที่ตรวจสอบได้ ใส่หน้า/หัวข้อถ้ามี
3. เนื้อหาเผยแพร่ภายใต้ **CC BY-SA 4.0** (ดู `LICENSES/`)
4. ไม่วินิจฉัยโรค ไม่แนะนำยา — ใช้เพื่อการศึกษาและการสื่อสารตำแหน่งอาการ
5. สถานะ (`review_status`):
   - `draft` — ร่าง ยังไม่ผ่านผู้เชี่ยวชาญ (แอปแสดงป้าย “ร่าง”)
   - `reviewed` — ผู้เชี่ยวชาญในทีมตรวจแล้ว
   - `verified` — อาจารย์/ผู้เชี่ยวชาญภายนอกรับรอง
6. ไฟล์ที่ขึ้นต้นด้วย `_` (เช่น `_template.md`) ไม่ถูกนำไปสร้างดัชนี

## รูปแบบไฟล์

ดู [`_template.md`](_template.md) — ส่วนหัว (frontmatter) + เนื้อหาแบ่งหัวข้อด้วย `##`
แต่ละหัวข้อ `##` คือ 1 ชิ้นข้อมูล (chunk) ที่ค้นหาและแสดงแยกกันได้

`regions` ต้องเป็นรหัสที่มีใน `data/body-pain-map.json` เท่านั้น (สคริปต์ตรวจให้)

## เพิ่ม/แก้เนื้อหา

```bash
python scripts/build-knowledge.py
```

แล้ว commit ทั้งไฟล์ใน `knowledge/` และ `data/knowledge.json` — CI ตรวจว่าสองส่วนตรงกัน
